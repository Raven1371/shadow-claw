## Executed validation

Ubuntu collected 436 tests: 436 passed, 0 failed, 0 skipped. Its offline
runner reported 436 passed, 0 failed, 0 skipped. Rocky collected 436 tests:
433 passed, 0 failed, 3 skipped; its offline runner reported the same counts.
The build workflows now apply the reusable skip classifier to all future
current-source runs so required Linux security skips block packaging and exact
reasons are retained as artifacts.

On both platforms, CI executed the extracted portable build, onefile build,
native package, and AppImage. Every format passed `--help`, `--version`,
doctor/preflight, Nmap-only, Nmap+Zeek, Graphviz SVG/PNG, output rename/delete/
reuse, and execution-log lifecycle smoke checks. DEB and RPM install, file-list,
execution, uninstall, and command-removal checks passed.
