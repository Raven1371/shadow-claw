Environment caveat (please read)
--------------------------------
pytest could NOT be installed in the environment where this release was
built: the host has no network access, so "pip install pytest" fails
(PEP 668 / no index reachable). The results below were produced with
"python run_tests.py", shipped in this archive. It imports each
tests/test_*.py module and runs every module-level test_ function with the
same pass/fail semantics this suite relies on, and provides a minimal pytest
shim (skip, raises, mark, fail) when pytest is absent. The tests are ordinary
pytest tests, so "python -m pytest -q" runs the identical suite where pytest
is available.

Issue 1 - execution-log pluralization
-------------------------------------
Message sites corrected (all now via the shared pluralize helpers):
  parser.py               "Parsed N hosts from ..."
  config.py               "Loaded configuration ... (N zones, N hosts)"
  flow_analysis.py        "Built N flows and N manual-review items"
  firewall_rules.py       "Generated N candidate inbound/outbound rules"
  role_inference.py       "Database service(s) open" -> service/services
  zeek_correlation.py     partial/ambiguous observation reasons
  cli.py                  "Zeek: N aggregated flows, N correlation findings,
                           N external dependency/dependencies, ..."
Generated execution.log and CLI stdout scanned for (s), (ies), was/were,
host(s), service(s), flow(s), communication(s), dependenc(ies), item(s),
rule(s), zone(s), finding(s), observation(s), aggregate(s), endpoint(s),
record(s), file(s), directorie(s): NONE present in either sample run.

Issue 2 - strict TSV detection
------------------------------
detect_zeek_format(first_meaningful_line) results:
  {"...":...}                 -> json
  #separator \x09             -> tsv     (and every ZEEK_TSV_DIRECTIVES token)
  #fields ts uid ...          -> tsv
  #random / #comment          -> indeterminate
  #separator_fake / #fieldsx  -> indeterminate
  #                           -> indeterminate
  ordinary text / [1,2,3]     -> indeterminate
  "" (blank)                  -> indeterminate

End-to-end (auto mode):
  #random comment\n...        -> format=indeterminate, usable=0, 1 file entry,
                                 bounded warning with filename:line, untrusted
                                 line NOT echoed.
  #separator_fake\n#fields... -> format=indeterminate, usable=0, 1 file entry.
  valid Zeek TSV header       -> format=tsv, usable=1.
  blank-led / BOM JSON        -> format=json, usable=1.
Explicit selection: --zeek-format json and tsv bypass detection and still
apply their structural validation.
