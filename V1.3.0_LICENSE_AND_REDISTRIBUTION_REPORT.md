Third-party terms remain independent. `licenses/DEPENDENCY_LICENSE_INVENTORY.json`
records CPython, runtime Python packages, PyInstaller 6.21.0 and its bootloader
exception, Graphviz/native inputs, packaging tools, and AppImageKit. Each Linux
build creates a package-specific native inventory from `dpkg-query` or `rpm`,
records versions/architectures/paths/SHA-256 values, and copies installed license
evidence. Any unattributed redistributed ELF file is a release blocker.

AppImage tooling is pinned to AppImageKit release 13, commit
`8bbf694455d00f48d835f56afaa1dabcd9178ba6`, immutable asset
`obsolete-appimagetool-x86_64.AppImage`, SHA-256
`df3baf5ca5facbecfc2f3fa6713c29ab9cefa8fd8c1eac5d283b79cab33e4acb`.
The exact-commit MIT license has SHA-256
`9cb22a08334c3a108ec4da96c1d6aea7a17a732fa9f5ca3413a9b4ce651397d8`.

`requirements.lock`, `requirements-build.lock`, and `requirements-dev.lock`
separate runtime, artifact-producing, and test inputs. CI installs the locks and
then installs the project with `--no-deps`, preventing silent dependency drift.

Automated gates inspect portable bundles, native package documentation paths,
AppDirs, native checksums, installed/uninstalled packages, representative Nmap
and Zeek analysis, Graphviz SVG/PNG, doctor/preflight, and lifecycle behavior.
Source archives are checked for licensing before release assembly. New licensed
rebuild results remain pending until the branch workflows complete.
